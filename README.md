# Reporting automatique PME

Ce projet transforme un export CSV brut en reporting Excel structuré.

## Problème

Beaucoup de PME produisent chaque mois des reportings manuellement depuis des exports Excel/CSV.

## Solution

Un script Python nettoie les données, calcule les indicateurs clés et génère automatiquement un fichier Excel prêt à envoyer.

## Résultat

- Données nettoyées
- CA total
- CA par mois
- Top clients
- Performance par source
- Export Excel formaté
